# Geodesic Dome Frequency & Strut Calculator

## 概要
Class I (Alternate) 正二十面体ベースのジオデシックドームについて、周波数（1V〜5V）と半径を指定してストラット長・本数・頂点座標を即座に計算するツール。

## 機能
- 周波数 1V〜5V 選択
- 半径入力（メートル）
- ドームタイプ選択（1/2 ヘミスフィア / 3/4 ドーム / フルスフィア）
- ストラットタイプ別の長さ係数・実長・本数・割合を一覧表示
- 素材見積もり（配管径・単価/m → 総延長・概算費用）
- オイラーの多面体定理 V − E + F = 2 の検証
- Canvas による上面図三角化投影
- 全周波数（1V〜5V）比較テーブル

## 使い方
1. 周波数・半径・ドームタイプを選択
2. 配管径と単価を入力（任意）
3.「Calculate」ボタンをクリック
4. ストラット詳細テーブル・上面図・比較テーブルが更新される
